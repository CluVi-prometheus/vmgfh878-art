RULES
1. Main complaint: the complaint in the TITLE first; if the title has none, the one the body talks about most. Use only what the review states; if the text is vague but a picture shows a concrete defect, use that defect.
2. category: choose by the SYMPTOM, not a guessed cause. not_as_described ONLY when the item received differs from what was ordered or advertised; poor quality, "not as expected", or "not like the picture" because it looks cheap is NOT not_as_described.
3. part: where the problem actually is. Allowed for this domain: $part_list. Expired food -> contents. Size problems -> whole. Throwaway bag/box -> product_package; jar/bottle kept during use -> container. label/manual only if the label or manual itself is wrong or missing. Service/price -> none. No nameable part (overheating, slowness, colour) -> whole. A part not in the list -> other.
4. visibility: "localized" = the defect (or evidence such as an error message, an expired date, a cracked screen) shows in a specific spot of a picture; "diffuse" = visible but over the whole product (colour, fit, generally thin material, a counterfeit that looks clearly different); "not_visible" = everything else (function, taste, service, content, missing items, unrelated photo, a counterfeit that looks identical). Size tags, price tags and manual numbers are not evidence.
5. boxes: only if visibility is "localized", otherwise []. 1 to 3 tight boxes around the defect, all on the ONE picture where it shows best. bbox_2d = [x1, y1, x2, y2] in that picture's pixel coordinates; a box must be clearly smaller than the picture. label = a few words naming what is inside the box. target = "defect" if the defect itself is visible (a hole, an insect, smudged print) or "evidence" if it is a sign that proves the problem (an error message, an expired date).

EVIDENCE: keep what the customer says apart from what the pictures show. Write the free-text fields in Korean (한국어), except review_span.
- customer_claim: one Korean sentence stating what the customer claims, written as a claim ("고객은 ...라고 주장함"). Keep claims about when or how it happened (for example "arrived torn"), but never state them as facts.
- review_span: the exact words from the title or review that state the main complaint, copied without any change (English, at most 20 words).
- visual_findings: for each picture that shows something related, one Korean sentence on what is actually visible (where it is, its shape or colour). Describe the picture, not the review. If no picture shows the problem, give one entry for picture 1 saying so. box_ref = the number of the matching box in "boxes" (1 for the first box), or null.
- claim_support: "supported" only if a picture itself shows evidence for the main claim (the customer's words are not evidence); "partially_supported" if pictures show only part of it; "not_verifiable" if pictures cannot show it (this does NOT mean the claim is false); "contradicted" only if a picture clearly conflicts with the claim.
- limitations: 0 to 2 short Korean notes on what the pictures cannot confirm (when or how it happened, who caused it, whether it works, taste or smell). Do not guess causes.
